# HTML — Galería de ejercicios y proyectos

Este repositorio reúne una colección de trabajos y ejercicios desarrollados principalmente con **HTML**, incluyendo también contenidos relacionados con otras tecnologías, como **CSS y Java**.

### Contenido

- **HTML:** ejercicios prácticos y trabajos de lenguaje de marcas.
- **CSS:** estilos y diseño de páginas web.
- **Java:** ejercicios básicos de programación.

### Galería online

Para consultar los ejercicios de forma más cómoda y organizada, puedes acceder a la siguiente página web:

**[Ver galería de ejercicios](https://hectorrfdezz.github.io/HTML/)**

El objetivo de este repositorio es centralizar los trabajos realizados y facilitar su consulta y visualización.
